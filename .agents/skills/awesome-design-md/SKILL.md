# Awesome DESIGN.md Skill

This skill provides direct access to 84+ exhaustive, reverse-engineered design system specifications (`DESIGN.md`). Each specification details color palettes, typography scales, spacing rules, card elevation, button geometries, border treatments, interaction states, and component recipes.

---

## How to Use in this Project

When the user asks to style, design, or rebuild an element, component, or full page in the aesthetic of a specific company or product:

1. **Locate the Brand's `DESIGN.md`**: Find the brand in the directory index below under [`design-md/`](./design-md/).
2. **Inspect the Specification**: Read [`./design-md/<brand>/DESIGN.md`](./design-md/) using `view_file`.
3. **Extract Relevant Tokens**:
   - **Colors**: Canvas, surface, borders/hairlines, primary brand accents, and contrast text.
   - **Typography**: Display headlines, body text, letter spacing (kerning), and line heights.
   - **Component Styles**: Button shapes (e.g. sharp, 6px athletic, or pill), inputs, cards, tabs, and focus rings.
   - **Do's and Don'ts**: Specific design rules and anti-patterns for that brand.
4. **Implement**: Apply the design tokens directly into CSS variables, utility classes, or React components while maintaining project accessibility and responsiveness.
